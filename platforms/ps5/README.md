# Smash Melee PS5 — experimental PlayStation 5 build

An **experimental native PS5 homebrew build** of the Vita port. The same game
code and GX layer run on the PS5. A small compatibility layer stands in for
the Vita system APIs, and an OpenGL 4.6 renderer
([ps5-opengl](https://github.com/blackbearreloaded/ps5-opengl), Mesa over AGC)
replaces GXM.

**This is early work.** Menus and most scenes run at 60 fps. Busy matches
can still dip below 60. Expect bugs, visual issues and crashes.

## What works

- Boots from your own `GALE01.iso`, with sound, saves and in-game movies
- **Video output** at 1080p, 1440p or 4K, chosen in **PS5 Options →
  Display**. A new output setting takes effect the next time the game
  starts.
- **Render resolution** of 544p, 1080p (the default), 1620p or 4K,
  supersampled to the output. Menus and matches have separate settings.
- Up to **4 controllers** for local multiplayer. Each pad must be signed in
  to a PS5 user (guest users work). Ports follow sign-in order.
- Button remapping in **PS5 Options → Controls**
- Hidden debug menu: on the Options screen press **Up, Up, Down, Down, Left,
  Right, Left, Right** on the D-pad, then click the **left half of the touch
  pad**

Controls: the left stick and D-pad move. Cross, Circle, Square and Triangle
map to A, B, X and Y. L1 and R1 are the triggers. The left half of the touch
pad is Z/SELECT. OPTIONS or the right half of the touch pad is START.
L3 + R3 saves a screenshot to `/download0`.

## Requirements to run

- A **jailbroken PS5** that can run homebrew folder titles. It has been
  tested on firmware 13.60 with kstuff 1.11, etaHEN and ShadowMountPlus.
- An **FTP payload** (port 2121) to copy files to `/data/homebrew`.
- Your own legally obtained, **uncompressed Super Smash Bros. Melee NTSC-U
  1.02 disc image** (`GALE01`), named `GALE01.iso`. RVZ/CISO images and other
  regions are not supported. The disc image is never included in a build or
  release.

## Install

1. Build it (below) or download the `melee-ps5-…` artifact from the **PS5
   build** GitHub Actions run, then unzip it to get `PPSA99701/`.
2. Copy the `PPSA99701` folder to `/data/homebrew/PPSA99701` on the PS5. You
   can use `platforms/ps5/tools/deploy-ps5.ps1 -Zip PPSA99701.zip -Ps5 <ip>`.
3. Copy your disc image to **`/data/homebrew/PPSA99701/GALE01.iso`**. The game
   reads it as `/app0/GALE01.iso`. Homebrew titles cannot see the rest of
   `/data`.
4. Let ShadowMountPlus register the title, then launch **Super Smash Bros.
   Melee** from the home screen.

Saves, settings and the shader cache live in the title's sandboxed
`/download0`. While the game is running, FTP can reach it at
`/mnt/sandbox/PPSA99701_000/download0/`.

## Building

Build on Linux or WSL (Ubuntu 24.04 is what CI uses). You need:

- GCC (x86-64). The decomp needs `scalar_storage_order`, which Clang lacks.
- Clang/LLD 18 and `libclang-rt-18-dev`
- Python 3, `curl`, `unzip`, `zip`, `git`
- The pinned PS5 toolchain:
  [ps5-native-app-boilerplate](https://github.com/blackbearreloaded/ps5-native-app-boilerplate)
  `4f531c4`, which brings ps5-payload-sdk v0.42, and the
  [ps5-opengl SDK 1.0.1](https://github.com/blackbearreloaded/ps5-opengl/releases/tag/v1.0.1)

```sh
sudo apt-get install build-essential clang-18 lld-18 llvm-18 libclang-rt-18-dev \
    python3 curl unzip zip git
bash tools/setup_ps5_ci.sh ~/ps5        # fetches and verifies the toolchain
export PS5_NATIVE_APP_TEMPLATE=~/ps5/bp
export PS5_OPENGL_PREFIX=~/ps5/ps5-opengl-sdk-1.0.1/sdk
export PS5_OPENGL_SRC=~/ps5/gl/ps5-opengl
bash platforms/ps5/build.sh             # --clean for a full rebuild
```

The output is `build-ps5/app/dist/PPSA99701/` plus `PPSA99701.zip`.

Build options (environment variables):

| Variable | Effect |
| --- | --- |
| `MELEE_PS5_LOG_HOST=<pc ip>` | Stream the log to `tools/log-listener.ps1` on TCP 18200 (development only) |
| `MELEE_PS5_TITLE_ID` / `MELEE_PS5_TITLE_NAME` | Title folder ID (default `PPSA99701`) and name |
| `BUILD_JOBS` | Parallel compile jobs |

The log is always written to `/download0/melee-ps5.log`. The OpenGL
runtime's own output goes to `/download0/gl-stdout.log`.

## How it fits together

| Piece | Role |
| --- | --- |
| `psp2_shim.c`, `shim/` | Vita kernel, IO, ctrl, audio and touch APIs on POSIX and PS5 services. Every symbol is renamed so none shadows a system export. |
| `ps5_services.c` | User service, DualSense pads (up to 4) and 48 kHz AudioOut |
| `ps5_memory.c` | MEM1 mapped below 4 GiB, plus the table that turns 64-bit pointers in disc data into 32-bit slots |
| `gl_game.c` | Frame queue, textures, render targets, EFB copies, EFB scaling, output mode, present |
| `gl_render.c` | GLSL port of the GX shader generator. Draws stream through persistently mapped buffers, and consecutive draws with the same state are merged. |
| `sce_sys/`, `art/` | Home-screen icon and backgrounds (original artwork, generated by `art/make_art.py`) |

Paths: `ux0:data/melee/GALE01.iso` maps to `/app0/GALE01.iso`, and the rest
of `ux0:data/melee/` maps to `/download0/`.
